Built an Automation Drawing Bot using Python, OpenCV, and PyAutoGUI.

The bot processes an image, detects contours, and automatically recreates the drawing on the screen.

This project is an improved version of my earlier Record & Replay Automation Bot, where I moved from replaying recorded actions to generating drawing actions from an image.

Currently working on improving accuracy and supporting more complex images.
